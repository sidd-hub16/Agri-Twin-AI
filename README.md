# AgriTwin AI – Smart Agriculture Monitoring System

## Project Overview

AgriTwin AI is an IoT-based smart agriculture system that monitors soil moisture, temperature, humidity, and rainfall in real time.
It uses sensor data to display field conditions on a web dashboard and supports smarter irrigation decisions, crop health monitoring, and risk assessment.

##Hardware Components

- ESP32 Development Board
- Soil Moisture Sensor
- DHT11 Temperature and Humidity Sensor
- Rain Sensor
- I2C LCD Display (16×2)
- LED Indicator
- Buzzer
- Jumper Wires and Breadboard
- USB Cable and Power Supply

## Working Principle (Workflow)

1. Sensors collect real-time soil and environmental data.
2. The ESP32 processes the sensor readings.
3. Data is displayed on the LCD and web dashboard.
4. The dashboard presents field conditions, risk indicators, and irrigation recommendations.
5. The LED and buzzer provide alerts based on configured conditions.
